Build a reusable procedural world generation framework for spherical, hex-based planets using **Unity**, **Blender**, and **C#**.

This repository contains the project developed for the Udemy course **Build a Hex-Based Planet Generator Engine in Unity & Blender**. The project builds a complete procedural planet generation system from the ground up, beginning with the planet mesh and progressing through terrain generation, organic landmasses, procedural assets, and cell visualization.

## Course

This repository accompanies the full Udemy course:

**[Build a Hex-Based Planet Generator Engine in Unity & Blender](https://udemy.billymcdaniel.com/#course_hex-planet-generator)**

The course walks through the complete development process and explains the techniques, architecture, and procedural generation systems used in this project.

## What You'll Build

The project demonstrates how to:

- Create a spherical hex-based planet mesh in Blender
- Import and configure the planet for use in Unity
- Separate the planet into individual cells
- Build reusable C# components for representing and managing cells
- Generate deterministic procedural worlds using random seeds
- Find and manage neighboring cells
- Grow organic islands and landmasses procedurally
- Assign terrain using a modular terrain rule system
- Create reusable environmental assets in Blender
- Generate variations of environmental assets
- Procedurally populate the planet with forests, mountains, structures, and other assets
- Generate visual outlines around individual planet cells
- Merge outline geometry into the generated cells
- Build the systems as a reusable foundation for larger procedural world projects

## About the Course

The goal of the course is not simply to produce one generated planet. It focuses on building a **reusable procedural world generation framework** that can be expanded for strategy games, city builders, simulations, survival games, and other projects built around procedurally generated hex-based worlds.

The systems are designed to demonstrate techniques that can be extended with additional terrain types, generation rules, biomes, environmental assets, and gameplay-specific data.
